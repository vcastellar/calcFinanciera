# CalcFinanciera

Web estática con calculadoras de finanzas personales y cálculos bancarios transparentes. El MVP incluye:

- Interés compuesto.
- Cuota de préstamo.
- Tabla de amortización.
- Hipoteca.
- Objetivo de ahorro.

Cada calculadora muestra una explicación breve, formulario, resultado principal, desglose, fórmula, ejemplo, preguntas frecuentes y advertencia de resultado orientativo.

## Desarrollo

```bash
npm install
npm run dev
npm test
npm run build
```
